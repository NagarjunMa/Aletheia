PHASE 28 — Downloadable Extension Zip Pipeline
Status: [x] COMPLETE — 2026-05-19
--------------------------------------------------------------------------------
Stood up build-time extension packaging so /ascendia-extension.zip
download links resolve to a real, current artifact without polluting git
history.

ARCHITECTURE (chose option B over commit-zip, GitHub Releases, runtime
endpoint after weighing repo bloat / infra cost / freshness / cold start):
  Pre-commit → detects ext source change → npm run build:extension
  Vercel deploy → npm run build → prebuild → same script → fresh zip
  Static asset served at /ascendia-extension.zip via Vercel edge CDN

      CORS-aware via getCorsHeaders().
